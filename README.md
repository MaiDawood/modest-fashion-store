# الأمل للزي الشرعي - متجر إلكتروني

## متجر إلكتروني حديث ومتجاوب للملابس النسائية المحتشمة

موقع متجر الأمل للزي الشرعي - متخصص في بيع الملابس النسائية المحتشمة مثل الحجاب والعباءة والنقاب والإكسسوارات.

### المميزات
- تصميم حديث وسهل الاستخدام
- واجهة مستجيبة متوافقة مع جميع الأجهزة
- تطبيق لغة عربية كاملة (RTL)
- نظام سلة تسوق متقدم
- تصفية وبحث عن المنتجات
- قائمة المفضلة
- نظام التقييمات والتعليقات

### التكنولوجيا المستخدمة
- HTML5
- CSS3 (Grid, Flexbox, Variables)
- JavaScript (ES6+)
- Local Storage API

### البدء
1. انسخ الملفات في مجلد
2. افتح ملف `index.html` في المتصفح
3. لا تحتاج إلى تثبيت أي برامج إضافية

### البنية الأساسية
```
modest-fashion-store/
├── css/              # ملفات التنسيق
├── js/               # ملفات JavaScript
├── images/           # الصور
├── *.html            # صفحات الموقع
```

### الصفحات
- الصفحة الرئيسية (index.html)
- المتجر (shop.html)
- تفاصيل المنتج (product-detail.html)
- عن المتجر (about.html)
- تواصل معنا (contact.html)
- سلة التسوق (cart.html)
- الدفع (checkout.html)
- الأسئلة الشائعة (faq.html)
